# Transcripts

One Markdown file per transcribed episode — self-contained, so any other
project can read a single file and get everything (metadata, tags, and the
full transcript) without touching `data/episodes.json` or any other part of
this repo.

## Filename

```
{published_date}-{podcast_id}-{title-slug}-{guid_suffix}.md
```

e.g. `2026-07-23-unhedged-how-jpmorgan-won-05a224.md` — sortable by date,
readable at a glance, and unique (the trailing suffix is a fragment of the
episode's RSS guid).

## Format

YAML frontmatter, then a blank line, then the full transcript as plain text:

```markdown
---
title: "How JPMorgan won"
podcast: "Unhedged"
podcast_id: "unhedged"
published_at: "2026-07-23T20:00:00+00:00"
guid: "6a625dad562e3ad88605a224"
link: "https://shows.acast.com/unhedged/episodes/how-jpmorgan-won"
duration: "18:57"
word_count: 3041
language: "en"
tags_source: "keyword"        # "claude-manual" (weekly Claude Code pass), "llm" (Claude API,
                               # if you set ANTHROPIC_API_KEY), or "keyword" (free regex tagger)
sectors: ["banks"]
themes: ["inflation", "rates-fed", "dealmaking", "regulation-antitrust"]
stocks: ["alphabet", "jpmorgan", "goldman-sachs", "morgan-stanley", "citigroup", "bank-of-america"]
sentiment: -0.6
summary: "..."                 # present once tags_source is "claude-manual" or "llm"
---

<full transcript text follows>
```

## Using these files in another project

Every field you'd need is in the frontmatter, so a consumer doesn't need to
parse `data/episodes.json` at all:

```python
import re, glob

def load_transcript(path):
    text = open(path).read()
    front, body = text.split("---\n", 2)[1:]
    meta = dict(re.findall(r'^(\w+):\s*(.+)$', front, re.MULTILINE))
    return meta, body.strip()

for path in glob.glob("data/transcripts/*.md"):
    meta, body = load_transcript(path)
    ...  # meta["podcast"], meta["sentiment"], body, etc.
```

(A real parser should use `yaml.safe_load` on the frontmatter block instead
of the regex above — this is just to show the shape.)

`data/episodes.json` still has the last word on structured querying (e.g.
"every episode where `stocks` includes `nvidia`") since it's a single JSON
array across all episodes, transcribed or not; each transcribed episode's
entry there also carries a `transcript_path` field pointing back to its file
here.

## Provenance

Generated by locally transcribing each episode's public RSS audio with
[faster-whisper](https://github.com/SYSTRAN/faster-whisper) (`pipeline/transcribe.py`),
then tagged by the offline keyword tagger (`tags_source: "keyword"`) and
later upgraded to Claude-quality tags via a free weekly manual review pass
(`pipeline/manual_review.py`, `tags_source: "claude-manual"` — see the main
README's "Getting Claude-quality tags for free" section) or, if you choose
to pay for the Anthropic API instead, `pipeline/enrich_claude.py`
(`tags_source: "llm"`). These are kept in this repo because it's private —
the underlying audio is copyrighted commercial podcast content, so don't
make this repo public without reconsidering that.
