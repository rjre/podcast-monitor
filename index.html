How the data updates

A scheduled GitHub Action runs pipeline/run.py to pull new episodes from each active feed and tag them against config/taxonomy.json — entirely offline, keyword-based, zero API cost. The results are committed to data/episodes.json (the full reusable dataset) and data/aggregates.json (precomputed rollups), so any other project can consume them without re-running anything. An optional Claude-powered enrichment pass (pipeline/enrich_claude.py) is available but off by default — wire it in only when you want deeper transcript-level nuance.

Data sourced from public podcast RSS feeds. Signals are derived from episode titles and show notes, not full transcripts — treat as a directional attention/sentiment indicator, not investment advice. See README for the full pipeline.
